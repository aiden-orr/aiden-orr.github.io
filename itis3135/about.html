About

This site is built in part to demonstrate work completed for ITIS 3135 - Front-End Web Application Development at UNC Charlotte in sections taught by Mr. von Briesen. The course gives students practical experience creating and maintaining front-end websites and web applications.

Throughout the course, students build several different websites while learning development tools, coding practices, validation, version control, file management, and web design principles. Additional information about the course can be found on the ITIS 3135 course website .

Tools Used in This Course

  • VS Code
  • Emmet within VS Code
  • SFTP using FileZilla
  • Git using GitHub Desktop and GitHub.com
  • Various browser development tools
  • The Accumulus Validator

The course includes several different websites and projects that demonstrate different areas of front-end web development.
